# Contributing to Waymaker AI Signal Protocol

## Accepted Contributions
We welcome contributions that improve the public-safe signal vocabulary and documentation, such as:
- New signal examples
- Schema enhancements
- Documentation improvements
- Human-in-the-loop principles

## Not Accepted
Submissions should avoid:
- Private/confidential data
- Proprietary materials
- Legal or emergency guidance
- Command-vault logic
- Paid methods

By contributing, you agree to abide by the Apache License 2.0.
