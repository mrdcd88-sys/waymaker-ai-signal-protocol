# Changelog

## [v0.1.0] - 2026-04-30
### Added
- Field signal JSON schema (`schemas/field_signal.schema.json`).
- Example JSON files for signals:
  - Scope Warning (`examples/scope_warning.example.json`)
  - Human Review Needed (`examples/human_review_needed.example.json`)
  - Benchmarking Requires Scope (`examples/benchmarking_requires_scope.example.json`)
  - Command Vault Request (`examples/command_vault_request.example.json`)
- Documentation:
  - Human-in-the-Loop Guidance (`docs/human-in-the-loop.md`)
  - Scope Signals Overview (`docs/scope-signals.md`)
- Boundary, Licensing, Contribution, and Security policy statements.

### Context
This release focuses on opening the Waymaker AI Signal Protocol for public use under Apache-2.0. No proprietary logic or private configurations are included.
