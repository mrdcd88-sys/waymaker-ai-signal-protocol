# Security Policy

## Reporting Vulnerabilities

If you discover a potential security vulnerability in the Waymaker AI Signal Protocol, please report it to us directly so we can address it promptly.

### How to Report
Email us at [security@example.com](mailto:security@example.com) with the subject `Vulnerability Report`. Include the following:
- Description of the vulnerability.
- Steps to reproduce the vulnerability.
- Any potential impact or scope.

### Response Time
We aim to respond to vulnerability reports within 7 business days. Critical issues will be addressed as quickly as possible.

Thank you for helping to keep the Waymaker AI Signal Protocol secure.
