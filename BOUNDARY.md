# Boundary for Waymaker AI Signal Protocol

This repository focuses on:
- Public-safe signal names
- Schemas
- Examples
- Human-readable documentation
- Basic routing concepts
- Human-in-the-loop principles

## Explicit Exclusions:
This repository does not include:
- Private routing architecture
- Command-vault logic
- Scoring models
- Proprietary doctrine stacks
- Confidential customer data
- Paid diagnostic methods
- Legal or emergency advice

### Commitment: Open the standard. Keep private systems private.
